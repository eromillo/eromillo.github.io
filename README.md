# Sitio público de KOMOKI

Sitio estático mínimo para `https://eromillo.github.io/` y el archivo `app-ads.txt` en la raíz que AdMob exige para verificar vendedores autorizados. No contiene fuentes de la app, credenciales, datos de usuarios, analítica ni scripts.

El fragmento de `app-ads.txt` se copió de la pantalla de configuración de la cuenta AdMob de KOMOKI el 10 de noviembre de 2026; corresponde al mismo editor de los bloques Android existentes. Publicar el archivo no equivale a obtener aprobación de anuncios: Google debe rastrearlo y la app debe poder vincularse a una tienda pública admitida.

La política y las instrucciones de eliminación se mantienen en el repositorio `eromillo/komoki-privacy`, bajo `/komoki-privacy/`. No duplicar documentos legales en este repositorio.

GitHub Pages: rama `main`, carpeta raíz, HTTPS. No hace falta un dominio de pago, servicios de backend o facturación adicional.
